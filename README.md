# APEX DIGITAL BANK

Create my APEX DIGITAL BANK app and responsive website from scratch. Build a premium, modern banking experience using navy/royal blue, white, and subtle gold accents, with polished responsive mobile, tablet, and desktop layouts.

Login screen: top half solid blue with a white “apex” logo and original octagon symbol. Center a white login card overlapping the blue/white sections with Username, Password, checked Remember me, unchecked Use token, large blue Sign in button, and Forgot username or password? link.

Below: Sign up • Open an account • Privacy •••

Add professional footer disclosures using Apex Digital Bank branding and appropriate generic banking/legal notices.

Build the full app with: registration, authentication UI, dashboard, balances, account/routing numbers, transactions/search, transfers, PIN confirmation, mobile deposit, notifications, scheduled transfers, favorite recipients, virtual debit card, credit score, budget, savings goals, spending insights, PDF statements, profile/settings, dark mode, loading/success/error states, and responsive navigation.

Use realistic data and  banking actions. Keep the architecture clean, functional, and lightweight. Use only necessary dependencies. Build everything now.
